# АБ «Движение» — дизайн-прототип

[Сайт](https://halitcan777.github.io/mooveab-preview/) · [3D-макеты](https://halitcan777.github.io/mooveab-preview/3d.html) · [Путь клиента](https://halitcan777.github.io/mooveab-preview/quiz.html)

Статический прототип архитектурного бюро. Медная палитра, адаптивные страницы, единый навигатор и интерактивные концептуальные модели домов. GitHub Pages публикует корень ветки `main`.

## Файлы

- `index.html` — сайт, маршруты, навигатор, расчёт, формы и ТЗ.
- `3d.html` — пять концептуальных моделей, WebGL без библиотек: вращение, масштаб, вид сверху и разбор на части здания.
- `quiz.html` — обзор пути клиента со ссылками в единый навигатор.
- `assets/*.png` — локальные изображения, полученные из тех же 3D-моделей.
- `tests/test_preview.py` — проверки маршрутов, размеров экранов и пользовательских сценариев через Playwright.

Открываются локально двойным кликом; для сайта папка `assets` должна лежать рядом с HTML. Внешних шрифтов, CDN, ключей и серверных зависимостей нет.

## Что работает

Навигатор разделяет клиента, организацию, подрядчика, поставщика и соискателя. Расчёт поддерживает ПП, РД, ПП+РД, отдельные разделы и надзор по явному выбору. Учитываются минимальные 50 м², тариф ПП для 201–209 м² и справочная цена для больших объектов. Постройки не добавляют выдуманные метры: пользователь указывает общую площадь под кровлей.

Стоимость видна до контактов. Расчёт можно изменить и скачать как текстовый файл. Параметры переходят в ТЗ, а выбранный дом — из портфолио в навигатор. Проверенная форма создаёт скачиваемую заявку; её содержание зависит от ветки обращения.

Черновик параметров проектирования хранится в `sessionStorage`. Контакты и свободный текст ТЗ не сохраняются туда, не попадают в URL и не отправляются наружу.

## Границы прототипа

- Сервер, отправка почты, CRM, платежи и генерация PDF не подключены. Интерфейс сообщает о подготовке заявки, а не о её отправке.
- Используется рабочий реестр из пакета ТЗ v0.8. Цены требуют финального утверждения бюро. Прототип не заменяет серверный расчёт в будущем продукте.
- 3D-модели — концептуальные макеты для демонстрации. Это не подтверждённые проекты бюро и не рабочие чертежи.
- Актуальные контакты, сведения о команде, реальные кейсы и содержимое готовых проектов должны быть подтверждены перед производственным запуском.

## Проверка

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/test_preview.py
```

Скриншоты и JSON-отчёт по умолчанию сохраняются в `/tmp/abd-preview-checks`. Для проверки публикации:

```sh
python3 tests/test_preview.py --base https://halitcan777.github.io/mooveab-preview --skip-layout
```
