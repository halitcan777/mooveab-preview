# АБ «Движение» — прототип сайта

Кликабельный прототип и 3D-портфолио для архитектурного бюро «Движение» (Пермь / Екатеринбург).

| Страница | Что это |
|---|---|
| [Прототип сайта](https://halitcan777.github.io/mooveab-preview/) | 42 маршрута: главная, ИЖС-хаб, 18 лендингов услуг, портфолио, готовые проекты, гайды, навигатор. Квиз с расчётом стоимости по прайсу бюро вызывается с любой страницы |
| [3D-портфолио](https://halitcan777.github.io/mooveab-preview/3d.html) | Пять проектов в одном пространстве: орбита мышью, переключение стрелками, разбор дома по разделам АР / КР / ИР / СМ |
| [Путь пользователя](https://halitcan777.github.io/mooveab-preview/quiz.html) | Схема квиза: 10 досок и кликабельный прототип расчёта |

Всё — статические HTML без библиотек и внешних запросов.

Прототип: структура собрана по техническому заданию заказчика, цены — по его прайсу.
Там, где цена в прайсе не утверждена, показывается «индивидуальный расчёт»: выдуманных сумм нет.
